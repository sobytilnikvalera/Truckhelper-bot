# 🚛 TruckHelper Bot — Пошаговая инструкция запуска

## Что тебе понадобится

- Компьютер (Windows, Mac или Linux)
- Интернет
- 10 минут времени

---

## Шаг 1: Установи Python

### Windows:
1. Перейди на https://www.python.org/downloads/
2. Скачай последнюю версию (кнопка "Download Python 3.x.x")
3. **ВАЖНО:** При установке поставь галочку ✅ "Add Python to PATH"
4. Нажми "Install Now"

### Mac:
1. Открой Терминал
2. Введи: `brew install python3` (если есть Homebrew)
3. Или скачай с https://www.python.org/downloads/

### Проверка:
Открой терминал (Windows: cmd или PowerShell) и введи:
```
python --version
```
Должно показать Python 3.9 или выше.

---

## Шаг 2: Создай папку для бота

### Windows:
1. Создай папку, например: `C:\TruckHelper`
2. Скопируй туда все файлы бота:
   - `bot.py`
   - `ec_rules.py`
   - `parking_search.py`
   - `database_setup.py`
   - `requirements.txt`

### Mac/Linux:
```bash
mkdir ~/TruckHelper
cd ~/TruckHelper
```
Скопируй файлы в эту папку.

---

## Шаг 3: Установи зависимости

Открой терминал/командную строку и перейди в папку бота:

### Windows:
```
cd C:\TruckHelper
pip install -r requirements.txt
```

### Mac/Linux:
```bash
cd ~/TruckHelper
pip3 install -r requirements.txt
```

Должно установиться без ошибок.

---

## Шаг 4: Запусти бота

### Windows:
```
python bot.py
```

### Mac/Linux:
```bash
python3 bot.py
```

Если всё ок, увидишь в терминале:
```
INFO - Bot starting...
INFO - Application started
```

---

## Шаг 5: Тестируй в Telegram

1. Открой Telegram
2. Найди своего бота (по имени которое ты дал в BotFather)
3. Напиши `/start`
4. Появится меню с кнопками

### Что проверить:
- Нажми "Начать смену" → "Начать вождение" → "Закончить вождение" → "Закончить смену"
- Нажми "Статус РТиО" — увидишь все лимиты
- Нажми "Статистика" — увидишь часы вождения
- Напиши `/admin` — увидишь список пользователей (только ты как админ)

---

## Шаг 6: Остановка бота

Чтобы остановить бота, нажми `Ctrl+C` в терминале.

---

## ⚠️ Важно

- Бот работает ТОЛЬКО пока открыт терминал и запущен скрипт
- Если закроешь терминал — бот перестанет отвечать
- Для постоянной работы 24/7 нужен VPS (сервер) — это следующий шаг

---

## Возможные проблемы

### "python не найден"
- Windows: переустанови Python с галочкой "Add to PATH"
- Mac: используй `python3` вместо `python`

### "pip не найден"
- Windows: используй `python -m pip install -r requirements.txt`
- Mac: используй `pip3`

### "Connection error" или "Timed out"
- Проверь интернет
- Если используешь VPN — попробуй отключить или наоборот включить

### Бот не отвечает в Telegram
- Убедись что в терминале написано "Application started"
- Убедись что токен правильный в файле bot.py
